# Приёмка MVP

Дата: 24 октября 2026. Изолированные проверки не отправляют сообщения рабочим пользователям.

Проверено на локальном PostgreSQL 16: 28 тестов проходят, включая два последовательных раунда, границы вторника/среды, отсутствие автопродления, перезапуск и одновременные запуски scheduler/worker, повреждённый/приостановленный черновик, история снимков, индивидуальные ответы, ачивки и аналитические ревизии. Миграция 0001 → 0002 проверена на профиле, опубликованной истории, feedback и ачивке; повтор migrate сохраняет данные. SQLite: 26 пройдено, 2 проверки PostgreSQL-блокировок пропущены намеренно.

Браузер Chromium: 375px и 1280px, вход, активности, профиль, история, карточка, feedback без горизонтального скролла. Имитация обрыва POST сохраняет ввод, повтор успешно сохраняет форму. Нет debug/тестовых данных в рабочем интерфейсе; тестовые данные браузера находятся только в локальной SQLite.

Render API: подтверждён проект MyTeam. Старый пустой web-service использует Go runtime; новая реализация — Python. Supabase API: подтверждён ACTIVE_HEALTHY проект MyTeam, исходно прикладных таблиц не было; создана отдельная закрытая схема и ограниченная роль. Токен Telegram getMe действителен, бот @myteam_official_bot; до настройки webhook был пуст.

Не подтверждены до фактической интеграционной проверки: рабочий deploy и подключение production PostgreSQL, cron, доставка реальному владельцу после активации, контакты двух реальных пользователей без username. Создание платного Render Cron требует разрешения. Служебный получатель по числовому ID ещё не привязан; исходящие сообщения выключены. Независимый Actions-monitor подготовлен, но не включается до защищённой настройки получателя.

Не считать пункты интеграционной приёмки выполненными на основании моков или одного HTTP 200 от management API. Окончательный статус и реальные ограничения обновляются после проверки деплоя.
