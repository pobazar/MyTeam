# AppBar: профиль, история, вход и оценка

Источник — предоставленный владельцем `tui-appbar-codex.zip`, сохранённый в [design-system/appbar](../../design-system/appbar/README.md). Он уточняет прежние решения по скриншотам. Реализация — `web/appbar.css` и общие обработчики в `web/app.js`.

Профиль, история и вход используют компактный Title + Back + None. Заголовок в AppBar виден сразу, в том числе при загрузке/ошибке; отдельный большой заголовок не дублируется. Семантический h1 сохранён для доступности. На входе возврат теперь в AppBar и ведёт на третий шаг знакомства, прерывая проверку кода. Первоначальное обязательное заполнение профиля продолжает отдельный gate без выхода в активности.

Оценка остаётся диалогом: компактный заголовок «Оценка активности», Close + Title + None на телефоне; Title + right icon на desktop. Порядок DOM перестраивается при смене ширины, чтобы соответствовать расположению кнопки. Крестик/Escape возвращают к экрану-источнику. Панель имеет отступ сверху для модального контекста.

Выбранные опубликованные варианты из `variants.primary`: Android / iOS18 / iOS26, middle=Title, left=Back или Close, right=None. Для desktop — варианты middle=title с right=none/icon; левый action на страницах следует общей анатомии компонента (desktop-список отдельное значение left не определяет).

- Desktop: высота64, заголовок по центру общей ширины, действия по краям; hover/pressed используют семантические цвета. Ширина диалога может быть меньше рекомендованных720: рекомендация не превращается в минимальную ширину окна.
- Android: высота56, иконка24, левый слот56, заголовок20/24 medium слева, pressed на action-hover-фоне. Длинный заголовок уходит в fade.
- iOS web: применяется web/iOS26-адаптация, включая на более старой ОС при поддержке CSS. Области нажатия44, заголовок17/20 semibold по центру симметричной области; при нехватке места смещается в доступную область слева и получает fade. Отступ16, при ширине≥428 —20, плюс safe-area. Стеклянные кнопки используются только внутри AppBar. Взята светлая web-переменная `#ffffffb3`; backdrop-filter — приближение, при отсутствии поддержки остаётся читаемый светлый фон. Нажатие масштабирует кнопку, reduced-motion отключает transition. Фон на скролле появляется линейно на0–32px, без тени панели. Это веб-адаптация, не нативный UINavigationBar и не обещание точного Liquid Glass.

Симметричные границы измеряются по реальному размеру кнопок и текста; нет пересечения заголовка с действиями. Для mobile iOS оставлены боковые области минимум60. Иконки/названия и значение title сохраняют доступный полный текст при визуальном fade.

По просьбе владельца полный прогон и новые скриншоты на этом этапе НЕ выполнялись. Проверены только синтаксис JS и diff. Визуальную проверку, мобильные браузеры, фокус/возврат, длинные заголовки, загрузку/ошибки и весь флоу необходимо включить в последующее финальное тестирование. Старые галереи отражают предыдущий AppBar.
