# Code Names

Адаптер code_names, version=1, minimum_participants=4, achievement_key=first_code_names. Реализация готова и участвует в авторотации. План 28.10.2026 Random Coffee / 04.11.2026 Code Names сохранён. Существующая системная пауза старого placeholder снимается в publish, ручная pause_origin=manual остаётся приоритетной.

## Подбор

Группы по четыре; остаток равномерно распределяется до пяти. По решению владельца, если это невозможно, допускается 6–7, без исключения записавшихся: 6→6, 7→7, 11→6+5. Примеры: 8→4+4, 9→5+4, 10→5+5, 12→4+4+4, 13→5+4+4, 14→5+5+4, 15→5+5+5. При 0–3 записавшихся группа не создаётся, записавшиеся получают обычный unmatched. Формальная проверка распределения не позволяет незаметно отбросить часть участников.

32 случайных варианта разбиения, приоритет минимального числа прежних контактов, затем давности повторов, затем коллег из одной команды. Это ограниченный поиск, глобальная оптимальность не обещается. Покрытие, отсутствие дублей и размеры проверяются перед публикацией. Один организатор на группу сохраняется тем же механизмом, что Coffee. Повтор подготовки сохраняет Meeting/Member/snapshot и ручные правки.

## Игра и обратная связь

МАЙТИМ организует общение, не хостит игру. Ссылка https://codenames.game/ проверена HTTP 200 / Codenames Online. Организатор выбирает время, создаёт голосовой звонок и комнату, отправляет ссылки участникам. Команды и капитаны выбираются в самой игре, команды могут отличаться на одного человека. Инструкции одинаково онлайн для коллег из одного и разных городов. Ссылка — отдельная кнопка в веб-карточке и Telegram-назначении, в новой вкладке с noopener/noreferrer в браузере.

Обратная связь общая: получилось → звёзды и необязательный комментарий; не получилось → необязательная причина. Первое заполнение без срока, окончательное неизменяемо. Победа, рейтинг 5 и реальный API игровой комнаты не требуются для подтверждения участия. Награда «Мастер ассоциаций» выдаётся однократно за первое outcome=yes; Coffee-награда от этого не появляется и не удаляется.

Каталог достижений в myteam/achievements.py. Профиль выбирает даты обоих ключей в одном person SELECT с подзапросами — прежний бюджет 2 SQL с учётом сессии сохранён. Клиент показывает соответствующую PNG, фактическую дату, название и описание. Старые достижения сохраняются; миграций БД нет. Изображение — оригинальная генерация, 1254×1254 PNG с прозрачностью, без стороннего логотипа.

## Проверка и ревью

120 серверных тестов прошли, включая распределения 0–100, реальные группы 4/5/7/11, полный цикл подготовки/публикации/оценки, идемпотентность, привязку организатора, Telegram-текст/ссылки, приватность и отсутствие лишнего SQL. Пять снимков только игры: code-names/index.html (галерея удалена перед релизом). Данные получены через настоящий Django API в одноразовой локальной PostgreSQL. Реальных сообщений и production-записей ради теста не было.

Внешняя игровая партия, создание комнаты, сторонняя авторизация и серверы codenames.game не являются нашей интеграцией и не тестировались как end-to-end. Приложение выдаёт ссылку и инструкции, как и требуется для этого формата.
