# Gartic Phone и Spyfall

Готовые адаптеры `gartic_phone/version=1` и `spyfall/version=1` включены в общую ротацию. Уже объявленные раунды, записи и текущая Code Names не заменяются. Новые форматы используют существующие профиль, недельный цикл, назначение организатора, Telegram outbox, историю, результат и оценку.

## Группы

Минимум 4 участника. Основа — четвёрки, остаток распределяется по одному между группами: 8 → 4+4, 9 → 5+4, 10 → 5+5, 13 → 5+4+4. При 5–7 участниках — одна группа, при 11 — 6+5. Ниже минимума действует общий сценарий нехватки участников.

Общий `four_person.py` содержит прежний алгоритм Code Names без изменения семантики version=1. Из 32 случайных распределений выбирается лучшее по повторным знакомствам, давности пересечений и парам из одной команды. История общая для всех активностей. Это мягкие предпочтения, они не исключают записавшихся. GeoGuesser сохраняет собственные размеры групп.

## Gartic Phone

Сайт https://garticphone.com/. Организатор предлагает время, создаёт звонок и комнату, отправляет ссылки, помогает всем подключиться и начинает с обычного режима. Игра — цепочки фраз, рисунков и догадок, 30–45 минут. Инструкция подчёркивает, что рисовать уметь не обязательно, темы должны быть комфортны коллегам, а при просмотре цепочек каждому стоит дать высказаться.

Достижение `first_gartic_phone` — «Вот это поворот!», с объёмной янтарной эмблемой, рисунком и карандашом.

## Spyfall

Сайт по выбору владельца: https://spyfall.adrianocola.com/. Организатор предлагает время, создаёт звонок и комнату, помогает участникам открыть роли на собственных устройствах. Один шпион пытается узнать локацию, остальные вычисляют шпиона по вопросам и ответам. Инструкция предлагает 30–45 минут на несколько раундов, чередовать собеседников и сохранять дружелюбный тон. Роли не показывают остальным; демонстрация экрана не предлагается.

Достижение `first_spyfall` — «Под прикрытием», с объёмной рубиновой эмблемой, шляпой, очками и картой.

## Данные, проверки и выпуск

Обе ачивки выдаются за первое подтверждённое участие (`outcome=yes` и оценка 1–5), независимо от победы. Отрицательный результат награду не выдаёт, повтор ответа не создаёт дублей. PNG имеют прозрачный фон и соответствуют стилю существующей коллекции.

Миграций нет. Выкладка: backend с адаптерами и каталогом, затем Pages с PNG. При откате после создания новых раундов необходимо сохранить оба адаптера version=1 для чтения истории. Исходные снимки, результаты и достижения сохраняются.

33 целевых теста прошли локально на изолированной SQLite: размеры 0–100, мягкие предпочтения, общий цикл и сохранность состава, организатор, ссылки и инструкции, предел длины Telegram, ачивки и API профиля, ротация и регрессия Code Names/GeoGuesser. Django check, проверка отсутствия миграций и синтаксис JS успешны. Сайты игр ответили HTTP 200; создание комнат и игровые партии этим не проверялись. Реальных тестовых рассылок нет. PostgreSQL CI проверяется перед слиянием.
