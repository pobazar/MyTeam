# Разовое приглашение — 26 октября 2026

Поручение владельца: в 18:00 Europe/Moscow пригласить зарегистрированных пользователей, ещё не записавшихся на Random Coffee 28 октября, по обычному шаблону с кнопками.

Отдельная ветка добавляет необязательный input `invite_at` в существующий workflow. Ручной запуск этой ветки с event=invite, round_date=2026-10-28 и invite_at=2026-10-26T15:00:00Z создаёт отложенный job на GitHub-hosted runner. Ветка не сливается в main и не деплоится. Действующий main workflow и backend менять для этого запуска не требуется.

Timer job имеет только contents:read и actions:write для dispatch штатного workflow этого же MyTeam в main. Он не получает ключи Render/Supabase/Telegram, не обращается к бэкенду и не выбирает получателей заранее. В 15:00 UTC он вызывает существующий main invite event с явным round_date. Обычный backend выбирает актуальных получателей, использует стандартные текст/кнопки, повторно проверяет enrollment перед отправкой и сохраняет outbox/dedup. Вторая отправка того же приглашения при повторном этапе блокируется штатными ключами. Область действия — только MyTeam.

Еженедельный cron не меняется. Timer ограничен ближайшим часом и пятиминутным допуском опоздания, проверяет invite event, Wednesday round_date, явный timezone и окно записи. Его отдельная concurrency group не блокирует обычные weekly events. GitHub Actions может задержать начало основного workflow; точность до секунды не гарантируется. Результат dispatch не равен подтверждению доставки: доставки проверяются в отдельном main run и статусах уведомлений. Для отмены до dispatch отменить timer run в GitHub Actions.

Миграций и изменений продуктового UI/БД нет. Проверки времени выполняются без реальной отправки; фактическая отправка в указанное время прямо авторизована владельцем. PR не сливать самостоятельно.
