# GeoGuesser

Адаптер `geoguesser`, version=1, включён в общую ротацию. Уже выбранные раунды и календарный план не меняются. Игра проходит на https://geoguesser.io/: МАЙТИМ не создаёт комнаты и не отслеживает игровой процесс.

Минимум 3 участника. Группы по 3, остаток распределяется по одному в разные группы: 4 → 4, 5 → 5, 7 → 4+3, 8 → 4+4, 10 → 4+3+3, 11 → 4+4+3. Пять человек в группе бывает только при пяти записавшихся. При 1–2 участниках используется общий сценарий нехватки участников.

Подбор использует 32 случайных распределения, как Code Names, и выбирает лучший по числу повторных знакомств, давности прошлых встреч и числу пар из одной команды. История общая для всех опубликованных активностей МАЙТИМ. Это предпочтения, а не ограничения: все записавшиеся распределяются при достижении минимума, оптимальность не гарантируется.

Организатор назначается и сохраняется общим механизмом. Он предлагает время, создаёт звонок, открывает игру и делится экраном. Все вместе ищут подсказки и обсуждают ответ; инструкция дружелюбно предлагает дать каждому высказаться, слушать друг друга и поддерживать совместный поиск. Организатор получает дополнительное объяснение своей роли в Telegram.

Общие запись, публикация, уведомления, история и форма результата переиспользуются. За первое подтверждённое участие (`outcome=yes` с оценкой 1–5) выдаётся `first_geoguesser` — «Мир в деталях», с отдельной объёмной PNG-эмблемой в стиле существующих достижений. Победа и правильность ответов не требуются. Миграции БД отсутствуют; профили, история и существующие достижения сохраняются.

Для выкладки сначала обновить backend с адаптером и каталогом достижения, затем Pages с новой PNG-эмблемой. После появления нового формата в раундах откат backend должен сохранять адаптер `geoguesser/version=1`, чтобы читать историю. Тесты, браузерные прогоны и реальные рассылки по указанию владельца не запускались.
