# TUI AppBar — дизайн-спецификация для Codex

Источник: **только `tui-appbar.fig`**. Предыдущие файлы и их содержимое не включены.

## Файлы

- `tui-appbar.json` — анатомия, правила, платформенные различия, геометрия, типографика, реальные наборы вариантов и собственные переменные компонента.
- `web-ios26.json` — стили и CSS-фрагменты из документации для веб-версии iOS 26, отдельно от нативного AppBar.

## Инструкция для Codex

1. При реализации навигационной панели читай `tui-appbar.json`, выбирай нужную платформу и **действительно существующий** вариант из `variants`.
2. Используй `designRules`, `platformExamples`, `typographyExamples` и `localVariables`; не переноси напрямую Figma px в dp/pt без проверки норм платформы.
3. Для веб-интерфейса iOS дополнительно смотри `web-ios26.json`. Фрагменты документации — не готовая CSS-библиотека, тестируй реальные эффекты браузера.
4. Не создавай отдельную кнопку Liquid Glass вне AppBar: гайд запрещает такое использование.
5. Если переменные ссылаются на внешние библиотеки, цветовые HEX в примерах — только визуальные ориентиры, не универсальные токены всех тем.
6. Не считай дополнительные комбинации старых/альтернативных наборов актуальными автоматически: при конфликте ориентируйся на описание своей платформы и платформенные API.

## Очистка

Исключены изображения, векторные иконки, прототипы, служебные поля и идентификаторы Figma, дубли импортированных компонентов, не относящиеся к AppBar коллекции, геометрия демонстрационных экранов и промежуточные структуры.

Сохранено поведение на iOS / Android / Desktop / Web, правила адаптивности, accessibility, состояния, прокрутка и анимации, примерные CSS-фрагменты и варианты компонента.
